# 个人主页（GitHub Pages）

这是一个纯静态个人网站，包含个人介绍、技术实践、摄影作品和思考分享。

## 本地预览
直接双击 `index.html`，使用浏览器打开即可。网页图片文件与 `index.html` 放在仓库根目录，网页会直接引用这些文件。

## 发布到 GitHub Pages
1. 将 `index.html`、`README.md` 和所有 JPG 图片上传到 GitHub 仓库根目录。
2. 仓库设置为 Public（免费 Pages 方案）。
3. 进入 Settings → Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/(root)`，保存。
6. 等待部署完成后访问 GitHub Pages 给出的地址。

## 修改内容
- 首页、关于我、关注领域、实践项目、摄影介绍和思考分享都在 `index.html` 中。
- 摄影原图经过适合网页展示的尺寸压缩，与 `index.html` 一同放在仓库根目录。
- 替换摄影作品时，保持文件名或同步修改 HTML 中的图片路径。
- 页面未填写真实姓名、联系方式或单位信息，避免未经确认公开个人信息。
